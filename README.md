# iot-reporting-api

WEB-FRAMEWORK SELECTION:
For the implementation of REST API, I chose fastAPI for web framework, because as a begginer in API's logic is easy to learn , easy to develop with, as it reduces a signific part of human error and by reviews i read is also high performance, but i didn't test that. Also a huge advantage for me was the swagger UI feature that fastAPI provide that gave me the opportunity to test the responses of my request without having to also create the front end.

LANGUAGE SELECTION:
The main programming language i used for the assingment was Python as it is simple with many healpfull libraries and also works great with fastAPI.
